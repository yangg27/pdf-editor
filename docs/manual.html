一、软件简介

PDF 编辑器是一款轻量、完全离线的本地桌面 PDF 工具，界面参照 WPS PDF 设计，采用 Ribbon 工具栏 + 三栏布局，提供页面可视化预览与完整的页面级编辑能力。所有操作均在本机完成，文件不会上传到任何服务器。

1.1 核心特性

特性说明
功能齐全覆盖 40+ 项操作：页面管理、批注、水印、加密、压缩、内容提取与导出
安全可靠原文件全程只读不修改；编辑在临时副本上进行，保存时才原子替换目标文件
可撤销内置撤销 / 重做栈，误操作可一键回退（默认保留最近 20 步）
加密兼容支持打开带口令的 PDF，也可为文档设置 AES-256 加密与权限限制
内存友好预览与缩略图采用缓存上限 + 像素上限策略，长时间浏览大文件不涨内存

二、安装与启动

2.1 使用发布包（推荐）

第 1 步　获取发布包中的 pdf-editor-win10.zip，解压到任意目录（如 D:\PDF编辑器）。
第 2 步　双击其中的 PDF编辑器.exe 即可运行。
提示：本软件为绿色免安装程序，无需安装、不写注册表，删除文件夹即可完全卸载。首次运行如遇 Windows 防火墙或安全提示，选择"允许运行"即可。

2.2 命令行参数

命令作用
PDF编辑器.exe启动图形界面
PDF编辑器.exe --version打印版本号
PDF编辑器.exe --help打印帮助信息
PDF编辑器.exe 报告.pdf启动并直接打开指定文件

2.3 使用源码运行（开发者）

第 1 步　确保已安装 Python 3.10 及以上版本。
第 2 步　在源码目录执行：pip install -r requirements.txt
第 3 步　执行 python main.py 启动程序。

四、打开文件与页面浏览

4.1 打开 PDF

方式一　点击 Ribbon「开始 → 打开」按钮，或按 Ctrl+O，在对话框中选择文件。
方式二　直接把 PDF 文件拖拽到程序窗口中释放。
方式三　双击 exe 时带上文件路径参数：PDF编辑器.exe 报告.pdf。
方式四　从「文件 → 最近打开」中快速选择最近用过的文件。

打开后左侧自动生成全部页面缩略图，中间显示第 1 页大图，标题栏显示文件名，状态栏显示总页数。

加密文档：若 PDF 设有打开口令，程序会弹窗要求输入口令；口令错误或取消输入则不会打开该文件。

五、页面管理

5.1 旋转页面

用于校正横向或倒置的扫描件。

第 1 步　定位到目标页（可多选）。
第 2 步　点击 Ribbon「开始 → 左转 / 右转 / 180°」。
第 3 步　预览区立即显示旋转结果；如有误可按 Ctrl+Z 撤销。

图 5　旋转前后对比：纵向页面变为横向（90°）

5.2 删除与复制页面

删除　选中页面后点击 Ribbon「开始 → 删除页」，或右键缩略图选择"删除所选页"。
复制　点击「开始 → 复制页」，将当前页复制并追加到文档末尾。
注意：程序要求文档至少保留一页。若试图删除全部页面，操作会被拒绝并提示。

5.3 移动与重排页面

逐页移动　选中页后点击 Ribbon「页面 → 上移 / 下移」，每次移动一位。
自由重排　点击 Ribbon「页面 → 重排」，在对话框中输入新页序，用英文逗号分隔，例如 3,1,2。

图 6　按 3,1,2 重排后：新第 1 页为原第 3 页，依次类推

注意：所填数字必须恰好是 1 到总页数的完整排列（每页出现且仅出现一次），否则程序会提示错误。

5.4 提取、拆分与插入

操作步骤
提取指定页点「页面 → 提取页」，输入页码（如 1,3,5），选择保存位置
拆分文件点「页面 → 拆分」，输入拆分方式：each 每页一个文件 / 数字 N 每 N 页一个文件 / 范围 1-3,4-6，再选择输出目录
插入 PDF点「页面 → 插入PDF」，选择文件，从子菜单指定插入位置（末尾 / 最前 / 当前页后）
插入空白页点「页面 → 空白页」，输入尺寸（a4/a3/a5/letter/legal/same），插入到当前页之后
统一页面尺寸点「页面 → A4」或「Letter」，把目标页统一为标准尺寸

图 7　合并：3 个文件（3+2+2 页）合并为 7 页的单一 PDF

图 8　拆分：按 1-1、2-3 两段拆分，生成 2 个独立文件

工具说明
高亮 / 下划线 / 删除线在文字上拖拽，生成对应标记
矩形 / 椭圆拖拽出矩形或椭圆框，用于圈注
图章单击落点，加盖预设图章（如 Approved）
手绘按住鼠标自由绘制曲线
便签单击落点生成便签图标，可填写文字内容
文本框拖拽出区域后输入文字，直接写在页面上

图 9　批注效果：高亮 / 下划线 / 矩形 / 便签 / 图章

6.1 管理已有批注

查看　切换到信息面板的批注页签，列出全文档所有批注（页码 / 类型 / 内容 / 说明）。
定位　双击批注行即可跳转到该批注所在页面。
删除　选中批注行后点「删除所选」；或点「全部清除」移除整篇文档的批注。

图 10　批注面板：集中管理全文档批注

6.2 密文遮盖（脱敏涂黑）

用于对外发布前彻底移除敏感信息。与普通黑色矩形不同，密文遮盖会把区域内的文字与图像真正从文件中删除，无法通过复制文本或提取图像还原。

第 1 步　点击 Ribbon「批注 → 涂黑脱敏」。
第 2 步　在预览区拖拽框选要遮盖的区域。
第 3 步　区域被涂黑，同时底层内容已被移除。

图 11　密文遮盖前后：左侧原文可读，右侧内容已被彻底移除

重要：密文遮盖是不可恢复操作。建议先「另存为」一份副本再执行脱敏。

七、水印、页码与页眉页脚

7.1 文字水印

第 1 步　点击 Ribbon「水印 → 文字水印」。
第 2 步　在对话框中填写水印文字、不透明度、旋转角度、字号与颜色。
第 3 步　确认后水印应用到目标页。

图 12　中文文字水印（45° 斜向、居中、半透明）

提示：程序会自动选用系统中文字体，并做空格与连字符保真校验——确保水印文字能用"查找"搜到、能正常复制，不会因字体映射问题变成不可搜索的字符。

7.2 图片水印

第 1 步　点击 Ribbon「水印 → 图片水印」。
第 2 步　选择图片（支持 png / jpg / jpeg／bmp）。
第 3 步　设置不透明度、缩放比例与旋转角度后确认。

图 13　图片水印（示例印章居中叠加于每页）

提示：建议使用带透明通道的 PNG 图片，叠加效果更自然。

7.3 页码与页眉页脚

页码　点「水印 → 插入页码」，可设置格式（支持 {page} / {total} 占位符）、位置、起始页码、字号，以及"首页不显示"。
页眉页脚　点「水印 → 页眉页脚」，分别填写页眉与页脚文本（支持 {page} / {total} / {name} 占位符），并各自选择对齐位置。

图 14　页码居中、页眉居中、页脚左对齐，三者互不遮挡

避免重叠：页脚默认靠左、页码默认居中，因此同时使用时不会叠在一起。若需调整，可在对话框中修改各自的位置选项。

九、安全与文档属性

9.1 加密与解密

加密　点「工具 → 加密码」，分别设置"打开口令"与"权限口令"，并勾选允许的操作（打印 / 复制 / 修改 / 批注）。输出文件使用 AES-256 加密。
解密　点「工具 → 解密码」，输入正确口令后即可移除限制。

图 17　加密保护对话框

请务必牢记口令：PDF 加密后无法通过本软件找回口令。口令遗失则该文件将无法打开。

9.2 文档属性

点「工具 → 文档属性」可编辑标题、作者、主题、关键字等元数据。填写规范的属性有助于文件检索与归档。

图 18　文档属性编辑对话框

9.3 书签与目录

添加　定位到页面后点「批注 → 加书签」，输入书签标题。
查看 / 跳转　切换到信息面板的目录书签页签，双击条目即可跳转。
删除　选中条目后删除。

9.4 压缩优化

点「工具 → 压缩优化」，程序会清理冗余对象、做字体子集化并对图像降采样。可选 DPI 与图片质量。

图 19　压缩效果：清理冗余对象 + 字体子集化 + 图像降采样

十一、常见问题（FAQ）

问题解决办法
双击 exe 没有反应确认系统为 Win10 及以上 64 位；将文件解压后再运行，不要在压缩包内直接双击。
预览区空白 / 未显示请先打开一个 PDF 文件；未打开文件时预览区会提示"打开一个 PDF 文件后在此预览"。
打开时提示"文件可能损坏"该文件不是有效的 PDF，或下载/传输过程中损坏。可用其他阅读器交叉验证。
中文水印显示为方块/乱码确保系统已安装中文字体（微软雅黑/黑体/宋体）。本版本已内置中文字体回退，正常情况下不会乱码。
水印文字搜索不到本版本已修复字体映射问题，水印与页码中的空格均可被搜索。若仍异常，请反馈具体字体环境。
拆分提示"无效页码范围"检查输入格式（如 1-3,4-6）及页码是否超出原文件总页数。
重排提示"必须是完整排列"输入数字须为 1…总页数的完整排列，不重复、不遗漏。
删除时报"不能删除全部页面"程序要求至少保留一页，请勿删除唯一剩余页面。
误操作了怎么办按 Ctrl+Z 撤销（可连续撤销最近 20 步），Ctrl+Y 重做。
忘记加密口令无法找回。加密 PDF 的口令不可逆，请务必妥善保管。
处理大文件较慢耗时取决于文件页数与内容；缩略图较多时首屏渲染会稍慢，之后浏览流畅。
原文件会被修改吗？不会。编辑在临时副本上进行，只有您主动点"保存"时才会写入；不保存则原文件完全不变。

12.2 稳定性与内存设计

机制说明
原文件隔离所有编辑在临时工作副本上进行，原文件全程只读
原子保存先写入同目录临时文件，再 os.replace 原子替换，避免写入中断损坏文件
撤销快照按内存上限自动裁剪（默认 20 步 / 96 MB），大文档自动降级而非卡死
预览缓存预览缓存上限 6 张、缩略图缓存上限 200 张，超出即淘汰
像素上限单页渲染像素上限 600 万，防止超大页面（或高倍缩放）撑爆内存
异常兜底底层错误统一包装为可读提示；界面异常与后台任务异常均被捕获，不会导致程序退出
