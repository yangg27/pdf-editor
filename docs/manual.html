一、软件简介

PDF 编辑器是一款轻量的本地桌面工具，界面参照 WPS PDF 设计，提供页面可视化预览与完整的页面级编辑能力。所有操作均在本机离线完成，文件不会上传到任何服务器，安全可靠。

当前版本（v0.2.0）支持以下 10 项核心功能：

功能说明
合并 PDF把多个 PDF 文件按顺序合并为一个文件
拆分 PDF按页码范围把一个 PDF 拆成多个文件
旋转页面将当前页顺时针旋转 90° 或 180°（校正扫描件方向）
重排页面调整页面先后顺序，如把第 3 页移到最前
删除页面删除当前选中的页面
提取页面按页码抽取指定页，另存为新文件
插入页面把另一个 PDF 的页面插入到当前位置/最前/末尾
文字水印在每页居中叠加文字水印，支持中文，默认 45° 斜向
图片水印在每页居中叠加图片（如公司印章、Logo）
提取文字把 PDF 中的文字内容提取出来并显示

二、安装与启动

2.1 使用安装包（推荐）

第 1 步　获取发布包中的 pdf-editor-win10.zip，解压到任意目录（如 D:\PDF编辑器）。
第 2 步　双击其中的 PDF编辑器.exe 即可运行。
提示：本软件为绿色免安装程序，无需安装、不写注册表，删除文件夹即可完全卸载。首次运行如遇 Windows 防火墙或安全提示，选择"允许运行"即可。

2.2 使用源码运行（开发者）

第 1 步　确保已安装 Python 3.10 及以上版本。
第 2 步　在源码目录执行：pip install -r requirements.txt
第 3 步　执行 python main.py 启动程序。
注意：源码运行需要 PyMuPDF、ttkbootstrap、Pillow 等依赖；打包成 exe 后无需任何依赖。

三、界面总览

程序启动后进入主界面，整体采用 WPS PDF 风格的三栏布局：顶部为菜单栏与 Ribbon 工具栏，左侧为页面缩略图导航，中间为页面预览区，底部为操作日志与状态栏。

图 2　主界面功能分区说明

编号区域作用
①Ribbon 工具栏按"文件 / 页面 / 旋转 / 插入 / 水印 / 工具"分组排列全部功能按钮
②页面缩略图导航显示全部页面缩略图，点击任意缩略图即可跳转到该页
③页面预览区大图预览当前页，支持滚轮翻页、缩放、适应宽度
④操作日志实时显示每一步操作的结果与输出文件路径
⑤状态栏显示当前页码、缩放比例，并提供上一页/下一页按钮
菜单栏：除工具栏按钮外，顶部菜单栏（文件 / 编辑 / 页面 / 插入 / 水印 / 帮助）提供同样的功能入口，快捷键 Ctrl+O 可快速打开文件。

四、打开文件与页面浏览

4.1 打开 PDF

第 1 步　点击工具栏 打开 按钮（或菜单"文件 → 打开 PDF…"，或按 Ctrl+O）。
第 2 步　在文件对话框中选择一个 PDF 文件并确认。
第 3 步　左侧自动生成全部页面缩略图，中间显示第 1 页大图，标题栏显示文件名，状态栏显示总页数。

4.2 翻页与缩放

操作效果
点击左侧缩略图直接跳转到对应页面
预览区滚动鼠标滚轮向下滚＝下一页，向上滚＝上一页
状态栏"上一页 / 下一页"逐页前后翻页
工具栏"缩放＋ / 缩放−"放大或缩小预览（20% ~ 500%）
工具栏"适应宽度"自动缩放使页面宽度铺满预览区
提示：页面预览由 PDF 引擎实时渲染，所见即所得的编辑结果。所有编辑操作都会输出到新文件，原文件保持不变。

五、功能一：合并 PDF

把多个 PDF 按选择顺序拼接成一个完整文件，常用于合并报告的各章节。

第 1 步　点击工具栏 合并 按钮。
第 2 步　在文件对话框中按住 Ctrl 或 Shift 多选待合并的 PDF（至少 2 个，按点选顺序排列）。
第 3 步　选择保存位置与文件名。
第 4 步　合并完成后自动载入结果文件，日志区显示"合并完成"。

图 3　3 个文件（3+2+2 页）合并为 7 页的单一 PDF

六、功能二：拆分 PDF

按页码范围把一个 PDF 拆成多个独立文件，适合把某一章节单独抽出。

第 1 步　点击工具栏 拆分 按钮。
第 2 步　在弹出的输入框中填写拆分范围，格式为 起始页-结束页，多段用英文逗号分隔，例如 1-3,4-6。
第 3 步　选择输出目录。
第 4 步　日志区列出生成的全部文件，命名形如 原名_part1_1-3.pdf。

图 4　按 1-1、2-3 两段拆分，生成 2 个文件

注意：页码从 1 开始且为闭区间；范围超出总页数时会提示错误，请先确认原文件页数。

七、功能三：旋转页面

用于校正横向或倒置的扫描件。旋转作用于当前显示页。

第 1 步　在左侧缩略图或预览区定位到要旋转的页面。
第 2 步　点击工具栏 ↻ 90° 或 ↻ 180° 按钮，确认后选择保存位置。
第 3 步　输出文件命名为 原名_rotated.pdf，随后自动载入并可预览旋转结果。

图 5　旋转前后对比：纵向页面变为横向（90°）

提示：若需对全部页面旋转，可分别定位到各页执行；如需连续旋转（如 180°），可对输出文件再执行一次 90°。

八、功能四：重排页面

调整页面顺序，例如把作为结论的第 3 页提到最前面。

第 1 步　点击工具栏 重排 按钮。
第 2 步　在弹出的输入框中填写新页序，用英文逗号分隔，例如 3,1,2。
第 3 步　选择保存位置，输出文件为 原名_reordered.pdf。

图 6　按 3,1,2 重排后：新第 1 页为原第 3 页，依次类推

注意：所填数字必须恰好是 1 到总页数的完整排列（每页出现且仅出现一次），否则程序会提示错误。

九、功能五：删除与提取页面

9.1 删除当前页

第 1 步　定位到要删除的页面（左侧缩略图点选）。
第 2 步　点击工具栏 删除页 按钮，确认删除提示。
第 3 步　选择保存位置，输出文件为 原名_del.pdf。
注意：至少需保留一页，若文件仅剩 1 页则无法继续删除。

9.2 提取指定页面

第 1 步　点击工具栏 提取页 按钮。
第 2 步　输入要提取的页码，逗号分隔，例如 1,3,5。
第 3 步　选择保存位置，输出文件为 原名_extract.pdf。

十、功能六：插入页面

把另一个 PDF 的页面插入到当前文档中，可插入到最前、末尾或当前页之后。

第 1 步　点击工具栏 插入 PDF 按钮（菜单"插入"中可选择插入位置：末尾 / 最前 / 当前页后）。
第 2 步　选择要插入的 PDF 文件。
第 3 步　选择保存位置，输出文件为 原名_inserted.pdf，总页数相应增加。

十一、功能七：添加文字水印

为每一页添加居中的文字水印，适用于内部资料、合同等标注场景，支持中文，默认呈 45° 斜向、半透明显示。

第 1 步　点击工具栏 文字水印 按钮。
第 2 步　在弹出的输入框中填写水印文字（默认"机密"），例如"机密 - 内部资料"。
第 3 步　选择保存位置，输出文件为 原名_watermarked.pdf。

图 7　中文文字水印效果（45° 斜向、居中、半透明）

提示：程序会自动选用系统中文字体（微软雅黑/黑体等），并内置中文字体回退，确保中文正常显示，不会出现乱码或方框。

十二、功能八：添加图片水印

为每一页叠加一张图片作为水印，常用于加盖公司印章或放置品牌 Logo。

第 1 步　点击工具栏 图片水印 按钮。
第 2 步　在文件对话框中选择图片（支持 png / jpg / jpeg）。
第 3 步　选择保存位置，输出文件为 原名_img_watermarked.pdf。

图 8　图片水印效果（印章居中叠加于每页）

提示：建议使用带透明通道的 PNG 图片，叠加效果更自然；图片会自动缩放至页面居中区域。

十三、功能九：提取文字

读取 PDF 中的文字内容，用于复制、检索或核对。

第 1 步　打开目标 PDF 后，点击工具栏 提取文字 按钮。
第 2 步　程序弹出"提取的文字"窗口，展示全文内容，可框选复制。
第 3 步　日志区提示提取完成及文字长度。

图 9　「提取的文字」结果窗口

注意：提取文字依赖 PDF 内置的文本层。若文件是纯图片扫描件（未做 OCR），将无法提取出文字，这属于正常现象。

界面底部的操作日志会记录每一步操作，包括打开的文件、输出的路径与结果，便于回溯核对。

十五、常见问题（FAQ）

问题解决办法
双击 exe 没有反应确认系统为 Win10 及以上 64 位；将文件解压后再运行，不要在压缩包内直接双击。
预览区空白 / 未显示请先通过"打开"载入一个 PDF 文件；未打开文件时预览区会提示"打开一个 PDF 文件后在此预览"。
中文水印显示为方块/乱码确保系统已安装中文字体（微软雅黑/黑体）。本版本已内置中文字体回退，正常情况下不会乱码。
拆分提示"无效页码范围"检查输入格式（如 1-3,4-6）及页码是否超出原文件总页数。
重排提示"order 必须是排列"输入数字须为 1…总页数的完整排列，不重复、不遗漏。
只删不掉最后一页程序要求至少保留一页，请勿删除唯一剩余页面。
处理大文件较慢处理耗时取决于文件页数与内容，属正常范围；缩略图较多时首屏渲染会稍慢。
原文件会被修改吗？不会。所有功能均输出到您指定的新文件，原文件保持原样。
